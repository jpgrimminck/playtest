## Setup
1. Install the **Live Server** extension in Visual Studio Code (for local testing).
2. Install Git locally (for committing directly from Visual Studio Code).
3. Determine your device IP address:
   - macOS: `ipconfig getifaddr en0`
   - Windows: `ipconfig`
4. On your smartphone, set the browser URL to `xxx.xxx.x.xx:port` (e.g., `192.168.0.10:5500`).
5. In Chrome on the smartphone, choose **Add to Home Screen**.
6. Rename the web app from **Play** to **Play locally**.
7. Tap **Add**.

## Running the App
1. In Visual Studio Code, open `index.html`.
2. Click **Go Live** (Live Server).
3. Launch the app on your smartphone via the **Play locally** home screen icon.
